Quartile ranking

Each participant's per-metric quartile/cluster rank, computed independently for each of the 5 performance measures over the current set of participants (higher value is better for all 5 metrics). Follows the same Classification Method currently selected in the chart above (Square quartiles, Diagonal quartiles, or K-Means clustering): Square and Diagonal quartiles reduce to the same percentile-based split for a single metric (the 2D "distance-to-corner" score diagonals uses is just the metric's own normalized value when there is only one axis); K-Means runs real 1-D k-means (k=4) on each metric's values independently, grouping by natural breaks in the data rather than equal population percentiles, with clusters ranked by mean (Q1 = highest-performing cluster). Try it yourself

This static page shows a fixed snapshot of the 14 participant scoring functions' results. To evaluate your OWN predictions against this benchmark -- with a declared, leakage-safe cross-validation procedure, a live-updating leaderboard chart and table, and your choice of CV splitting strategy -- download the full package below and run it on your own machine (it ships with its own local web server; no installation beyond Python 3 is required).
Download the full benchmark package (oeb_ppi_benchmark.zip) -- includes this page's live, interactive version plus every OpenEBench submission file. After extracting it, run: cd oeb_ppi_benchmark && python3 serve_local_openebench_visualizer.py, then open http://localhost:8080/.

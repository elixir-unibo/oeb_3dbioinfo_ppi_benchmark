Each participant's per-metric quartile/cluster rank, computed independently for each of the 5 performance measures over the current set of participants (higher value is better for all 5 metrics). Follows the same Classification Method currently selected in the chart above (Square quartiles, Diagonal quartiles, or K-Means clustering): Square and Diagonal quartiles reduce to the same percentile-based split for a single metric (the 2D "distance-to-corner" score diagonals uses is just the metric's own normalized value when there is only one axis); K-Means runs real 1-D k-means (k=4) on each metric's values independently, grouping by natural breaks in the data rather than equal population percentiles, with clusters ranked by mean (Q1 = highest-performing cluster). Submit new predictions

Upload a scoring-function predictions file and see how it ranks against the 14 package participants, under a declared, leakage-safe cross-validation splitting procedure -- computed entirely in your browser (the file is never uploaded anywhere).
Every number shown here is a held-out, cross-validated metric: for each fold of the chosen splitting strategy, the decision threshold used by Balanced Accuracy / F1 / MCC is learned only from the other folds (Youden's J statistic), never from the held-out fold itself. This is different from (and stricter than) the plain resubstitution comparison against the manuscript shown in the Results section above. All computation happens client-side in JavaScript -- your file is read locally via the browser's File API and never leaves your machine.
